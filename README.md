# GenLayer AI Intelligent Contracts

A collection of 5 AI-powered Intelligent Contracts 
built on GenLayer Testnet Asimov using LLM-based 
on-chain consensus and Optimistic Democracy.

## Contracts

| Contract | Description |
|---|---|
| AI Sentiment Voter | Analyzes text sentiment on-chain |
| AI Language Detector | Detects language of any text |
| AI Joke Generator | Generates jokes by topic via AI |
| AI Country Guesser | Guesses country from hints |
| AI Translator | Translates text to any language |

## How It Works

Each contract uses GenLayer's `gl.vm.run_nondet_unsafe()` 
with leader/validator pattern to reach Optimistic Democracy 
consensus across multiple AI validators running different LLMs.
